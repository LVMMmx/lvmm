# LVMM Cluster Guide

A practical guide for using the CNyN/LVMM HPC cluster.

## Contents
- Access and authentication
- File transfer
- Software modules
- SLURM job execution

## Quick start
1. Connect to the cluster using your institutional credentials.
2. Transfer files with `scp` or `rsync`.
3. Load the required software modules.
4. Submit jobs with `sbatch`.
